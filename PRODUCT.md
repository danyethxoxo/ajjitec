# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

AJJITEC tiene dos públicos principales: visitantes que consultan el catálogo y los servicios de la empresa, y el equipo interno que administra clientes, inventario, cotizaciones y accesos desde el portal.

## Product Purpose

El sitio público presenta a AJJITEC, sus productos y sus servicios técnicos. El portal autenticado concentra la operación interna: clientes, inventario con fotografías, descripciones y precios, cotizaciones, usuarios, perfiles y futuros reportes o dashboards.

## Positioning

AJJITEC combina la presentación comercial de equipos para la industria con un espacio operativo propio para mantener ordenados los datos comerciales y acelerar la generación de cotizaciones.

## Operating Context

Los visitantes navegan el sitio público y consultan productos o contacto. El personal autorizado inicia sesión y trabaja con roles para consultar o modificar la información operativa según sus permisos.

## Capabilities and Constraints

- El sitio se publica como una aplicación web estática en GitHub Pages.
- Supabase proporciona autenticación, perfiles, roles y persistencia de datos.
- Las funciones actuales incluyen login, registro, recuperación de contraseña, gestión de perfiles, usuarios, clientes, inventario, cotizaciones y un módulo preparado para facturas.
- El cambio visual debe conservar las funciones, rutas, datos, permisos y controles existentes.

## Brand Commitments

- El nombre AJJITEC y el logo existente deben conservarse.
- La nueva identidad visual debe abandonar la interfaz oscura y usar una base blanca, plana y descansada, con tonos azules derivados del logo.
- El cambio aplica de forma consistente al sitio público y al portal autenticado.

## Evidence on Hand

- Logo de AJJITEC en `assets/ajjitec-logo.png`.
- Contenido y rutas existentes en las páginas HTML del repositorio.
- Referencia visual proporcionada por el usuario para la estructura del dashboard.
- No se deben inventar testimonios, métricas comerciales ni datos de clientes.

## Product Principles

- Claridad antes que decoración.
- Datos operativos fáciles de escanear.
- Una identidad coherente entre presentación pública y operación interna.
- Menos fatiga visual mediante superficies claras, contraste legible y acentos controlados.

## Accessibility & Inclusion

La interfaz debe conservar contraste legible, estados de foco visibles, navegación responsive y formularios utilizables en escritorio y móvil.
